 ## 一、数据存储单元

#### 1、计算机存储单元

- 硬盘
- 内存
- CPU(寄存器)

#### 2、寄存器

- 寄存器是位于CPU内部（每个CPU核心都有对应一套寄存器）
- 通用寄存器-EAX EBX ECX EDX ESP EBP ESI EDI
- 段寄存器-CS SS DS ES FS GS
- 标志寄存器-EFLAGS
- 指令指针寄存器-EIP

##### 2.1 通用寄存器

| 寄存器 | 用途（常用）         | 编号 | 范围                  |
| ------ | -------------------- | ---- | --------------------- |
| EAX    | 累加器 乘除指令      | 0    | 0x00000000~0xFFFFFFFF |
| ECX    | 循环计数器           | 1    | 0x00000000~0xFFFFFFFF |
| EDX    | I/O指针              | 2    | 0x00000000~0xFFFFFFFF |
| EBX    | DS段的数据指针       | 3    | 0x00000000~0xFFFFFFFF |
| ESP    | 堆栈指针指向线程栈顶 | 4    | 0x00000000~0xFFFFFFFF |
| EBP    | 堆栈指针指向线程栈底 | 5    | 0x00000000~0xFFFFFFFF |
| ESI    | 字符串操作源指针     | 6    | 0x00000000~0xFFFFFFFF |
| EDI    | 字符串操作目标指针   | 7    | 0x00000000~0xFFFFFFFF |

##### 2.2 通用寄存器对应关系

| 32Bit | 16Bit | 8Bit |
| ----- | ----- | ---- |
| EAX   | AX    | AH   |
| ECX   | CX    | AL   |
| EDX   | DX    | CH   |
| EBX   | BX    | CL   |
| ESP   | SP    | DH   |
| EBP   | BP    | DL   |
| ESI   | SI    | BH   |
| EDI   | DI    | BL   |
