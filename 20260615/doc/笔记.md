## 一、汇编环境

- 创建工程项目（空项目）
- 右键工程项目->生成依赖项->生成自定义->masm
- 右键选中源文件->添加->新建项->Main.asm（任意类型修改文件后缀即可）
- 扩展->管理扩展->联机->ASMDUDE->重启Visual Studio后 点击modify安装扩展
- 右键工程项目->属性->链接器（高级）->入口点（main）
- 随堂代码

```assembly
.586
.model flat, stdcall
option casemap:none


.data


.code
main proc
 
 ret
main endp
end
```
