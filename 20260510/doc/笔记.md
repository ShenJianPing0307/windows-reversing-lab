## 一、汇编环境搭建

1. 创建工程项目(空项目)
2. 右键工程项目 -> 生成依赖项 -> 生成自定义 -> masm
3. 右键源文件 -> 添加 -> 新建项 -> Main.asm(任意类型修改文件后缀即可)
4. 扩展 -> 管理扩展 -> 联机 -> **ASMDUDE** -> 重启Visual Studio 点击 modify 安装扩展
5. 右键工程项目 -> 属性 -> 连接器(高级) -> 入口点(main)

```assembly
1  .586
2  .model  flat, stdcall
3  option  casemap:none
4
5  .data
6
7
8  .code
9  main proc
10
11      ret
12  main endp
13  end
```
