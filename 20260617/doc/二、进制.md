## 六、进制转换

- 加权位计数发

最低有效为开始，值不为0的位-- 位值*进制^序号

- 二进制转十进制

```c
 BIN 1101 1011
 DEC 2^0+2^1+2^3+2^4+2^6+2^7 = 1+2+8+16+64+128 =219 (二进制从右向左)
```

- 十进制转二进制

```c
DEC 219
    
219 / 2 = 189 ...  1
189 / 2 = 54 ...  1
54 / 2  = 27 ... 0
27 / 2 = 13 ... 1
13 / 2 = 6 ... 1 
6 / 2 = 3 ... 0
3 / 2 = 1 ... 1

从最小面的 商 -> 余数  1101 1011
```

- 十六进制转十进制

```c
0xDB

11 * 16^0 + 13 * 16^1 = 219
```

- 十进制转十六进制

```c
DEC 219

219 / 16 = 13 ... 11   // 0XDB
    
DEC 999
999 / 16 = 62 ... 7
62 / 16 = 3 ... 14

// 0X3E7
    
```

## 七、进制拓展

- 计算机中任何数据（程序、文件、图片、视频...）都是以二进制形式来进行存储
- 二进制数（binary）-位/Bit -0/1
- 最高有效位（Most significant）最右边的有效位
- 最低有效位（least significant）最左边的有效位
- 16进制数来表示2进制数- 1个16进制数可以描述4个二进制位的数
