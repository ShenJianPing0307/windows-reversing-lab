## 一、机器语言

机器语言（machine language）数字语言-设计成为CPU计算机器能理解的语言

- 计算机-cpu-心脏-控制计算机的运行

- amd-intel-指令集-cpu机器语言
- 机器语言-二进制（0/1）
- 加法操作 0111000100101110

## 二、汇编语言

汇编语言（assembly language）

- 助记符/汇编指令
- 机器语言-》加法操作 0111000100101110
- 汇编语言-》加法操作 Add
- 汇编语言语机器语言是一对一的关系-》汇编语言指令对应机器语言指令（1v1）

## 三、高级语言

- 高级语言

```c
#include <stdio.h>

int main()
{
	int a = 10;
	int b = 5;
	int c = a + b;

	return 0;
}
```
