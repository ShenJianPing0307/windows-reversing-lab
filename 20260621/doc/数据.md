## 一、数据-存储宽度

#### 1、数据宽度

- 计算机存储数据是有宽度限制的
- BIN 1000 1100 1010 1011 1000 1100 1010 1011
- 数据宽度-8-16-32-64
- 最高有效位以及最低有效位是基于当前数据宽度而言的最低有效位是可以确定的

#### 2、内存宽度

- 内存最小的单位是字节
- 1字节 = 8比特位
- 1Byte = 8Bit

| 宽度          | 位数 | 范围（十六进制）                            | 范围（二进制）        |
| ------------- | ---- | ------------------------------------------- | --------------------- |
| 字节（Byte）  | 8    | 0x00~0xFF                                   | 0000 0000 ~ 1111 1111 |
| 字（WORD）    | 16   | 0X0000~0xFFFF                               |                       |
| 双字（DWORD） | 32   | 0X0000 0000~0xFFFF FFFF                     |                       |
| 四字（QWORD） | 64   | 0X0000 0000 0000 0000~0xFFFF FFFF FFFF FFFF |                       |

```c
#include <stdio.h>
#include <Windows.h>

int main()
{
	// 数据类型 变量名 = 初始值;

	// 定义变量
	BYTE a = 0b00000000;

	//变量赋值
	a = 0b111111110; // 9个Bit位，截断高位 0x1FE  0xFE

	// 定义变量
	WORD b = 0b111111110; //WORD 2个字节，16Bit 可以存下 9个Bit  0x1FE


	return 0;
}

```

## 二、数据-整数存储

#### 1、整数存储

- 整数类型
  - 正数
  - 负数
  - 0
- 存储宽度

| 宽度          | 位数 | Unsigned整数范围                            | Signed负数范围                              |
| ------------- | ---- | ------------------------------------------- | ------------------------------------------- |
| 字节（Byte）  | 8    | 0x00~0xFF                                   | 0x00~0x7F - 0X80~0xFF                       |
| 字（WORD）    | 16   | 0X0000~0xFFFF                               | 0x0000~0x7FFF - 0X8000~0xFFFF               |
| 双字（DWORD） | 32   | 0X0000 0000~0xFFFF FFFF                     | 0X00000000~0x7FFFFFFF-0X80000000~0xFFFFFFFF |
| 四字（QWORD） | 64   | 0X0000 0000 0000 0000~0xFFFF FFFF FFFF FFFF |                                             |

- 整数的存储规则

|      | Unsigned         | Signed                                              |
| ---- | ---------------- | --------------------------------------------------- |
| 原码 | 数值本身的绝对值 | 最高有效位（MSB）是符号位，其余各位数值本身的绝对值 |
| 反码 | 反码和原码一样   | 符号位为1，其余各位对原码进行取反                   |
| 补码 | 补码和原码一样   | 反码加1                                             |

| 数据宽度为1Byte | 1         | -1        | 9         | -4        |
| --------------- | --------- | --------- | --------- | --------- |
| 原码            | 0000 0001 | 0000 0001 | 0000 1001 | 0000 0100 |
| 反码            | 0000 0001 | 1111 1110 | 0000 1001 | 1111 1011 |
| 补码            | 0000 0001 | 1111 1111 | 0000 1001 | 1111 1100 |

```c
#include <stdio.h>
#include <Windows.h>


int main()
{
	// unsigned char == byte
	signed char a = 1;

	a = -1;

	a = 9;

	a = -4;


	return 0;
}
```
